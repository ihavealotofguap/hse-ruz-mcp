# Безопасность

Об уязвимостях сообщайте приватно через
[Security Advisories](https://github.com/ihavealotofguap/hse-ruz-mcp/security/advisories/new),
а не в открытых issue.

Поддерживается последняя опубликованная версия.

Сервер не хранит учётных данных и обращается только к `ruz.hse.ru/api` без авторизации.
